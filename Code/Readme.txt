Due to copyright regulations imposed by ADNI, the file "threesample_MRI.mat" loaded in the MATLAB script "main_CPD_LS.m" is not shared on this repository. When loaded, the data would be a 240x240x155x3 tensor containing three MRI images each of size 240x240x155.

CPD factors of the first sample calculated for various CP ranks (r = 5, 10, ..., 205) are provided in the file "MRI_samp10_CPD_r5to205.mat".

The user must request MRI data on the ADNI website. If such data samples are used, the CPD factors in "MRI_samp10_CPD_r5to205.mat" must be recalculated for the new data.
