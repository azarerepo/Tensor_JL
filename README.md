# Tensor_JL
Oblivious subspace embeddings for tensors.

MATLAB implementations of the experiments in the paper:

Iwen, M. A., Needell, D., Rebrova, E., & Zare, A. (2021). Lower memory oblivious (tensor) subspace embeddings with fewer random bits: modewise methods for least squares. SIAM Journal on Matrix Analysis and Applications, 42(1), 376-416.
